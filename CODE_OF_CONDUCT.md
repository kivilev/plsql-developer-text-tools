# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive in issues, discussions and pull requests; harassment, insults and personal
attacks are not accepted.

To report unacceptable behavior, contact the maintainer privately, [@kivilev](https://github.com/kivilev)
(e-mail on the GitHub profile). Reports are handled confidentially. The maintainer may remove comments, lock threads
or block participants who violate the code.
